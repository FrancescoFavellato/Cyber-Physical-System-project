# Cyber-Physical Systems Project

This repository contains the project for the **Modeling and Control of Cyber-Physical Systems** course at **Politecnico di Torino**.

---

## 📂 Repository Structure

The project is divided into two main parts:

* **Part I**: 
  * `CPS_Project_Part_I.pdf` - Complete report covering the first part of the project.
  * `Simulazione/` - MATLAB code for the algorithms (OPGD, AOPGD, OPAM, AOPAM).

* **Part II**:
  * `CPS_Project_Part_II.pdf` - Detailed report covering the second part of the project.
  * `Simulazione/` - MATLAB scripts and functions for control and main simulation scripts.
